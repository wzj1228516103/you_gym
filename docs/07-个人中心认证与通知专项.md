# YOU GYM 个人中心、认证与通知专项

版本：1.0  
更新日期：2026-08-14

## 1. 范围

个人模块管理身份、身体资料、目标、设备、提醒、隐私和帮助。认证使用手机号 + 阿里云短信验证码；短信只用于登录/注册验证码、账号安全和重要系统通知。训练提醒、饮食提醒和普通计划提醒使用 App Push 或本地通知。

## 2. 认证流程

### 2.1 页面状态

| 页面 | 核心操作 | 必须状态 |
| --- | --- | --- |
| AUTH-01 手机号登录 | 输入手机号、获取验证码 | 空、格式错误、倒计时、发送失败、网络失败 |
| AUTH-02 验证码校验 | 输入 6 位验证码 | 错误、过期、重发、锁定、成功 |
| AUTH-03 协议与隐私 | 查看并勾选协议 | 未勾选阻止继续、文档加载失败 |
| ONB-01 身体基础数据 | 输入身高、体重、性别/年龄 | 校验、跳过可选项、保存 |
| ONB-02 训练目标 | 选择目标 | 单选、修改说明 |
| ONB-03 经验与频率 | 选择经验和频率 | 单选、多选、冲突提示 |
| ONB-04 场地与器械 | 选择训练地点/器械 | 多选、无器械模式 |
| ONB-05 推荐生成完成 | 查看推荐依据 | 加入计划、稍后设置 |

### 2.2 短信验证码规则

- 发送前校验手机号格式、IP 和设备风险。
- 单手机号 60 秒内只能发送一次；单手机号每日上限、单 IP 上限和设备指纹上限由服务端配置。
- 验证码为 6 位数字，服务端只保存哈希和过期时间，默认 5 分钟有效，成功或达到错误上限立即失效。
- 连续错误达到阈值后锁定短时段，并提供“稍后再试”文案，不透露账号是否存在。
- 阿里云响应只写入脱敏的发送日志，禁止把供应商完整错误信息返回客户端。
- 生产模板需通过阿里云审核；短信内容不包含健康数据、训练数据或营销文案。

### 2.3 Token 与设备

- 登录成功返回短期 access token 和可轮换 refresh token。
- refresh token 按设备存储，可在个人中心查看设备列表并远程退出。
- iOS 使用 Keychain，Android 使用 Keystore/Encrypted Storage；禁止明文写入 AsyncStorage。
- 注销账号会吊销所有 refresh token，并清理推送 token 映射。

## 3. 首次设置与资料完整度

资料分为“开始训练必填”和“个性化推荐可选”：

- 必填：目标、经验、训练场地至少一项。
- 可选：性别、年龄、身高、体重、器械、每周频率、单次时长。
- 体重和身高修改保存历史，不覆盖过去训练记录中的展示快照。
- 资料完整度仅用于提示，不得用进度条制造压力。

首次设置完成后生成推荐计划；用户可以跳过并在 PLN-01 再次设置。推荐解释至少展示目标、经验、地点/器械三项匹配原因。

## 4. 个人页面

### PRO-01 个人首页

展示头像/昵称、连续训练天数、最近一次训练、当前计划和饮食记录摘要。顶部使用编辑入口，隐私敏感数据不出现在锁屏通知或分享图中。

### PRO-02 身体数据

展示身高、体重、可选体脂率、记录日期和趋势。编辑时支持单位切换（kg/lb、cm/in），内部统一公制保存。删除历史数据需二次确认。

### PRO-03 目标与经验

展示目标、经验、周频率、场地和器械。修改后说明会影响推荐和目标计算，但不修改已完成训练。

### PRO-04 提醒设置

分为训练提醒、饮食记录提醒、休息计时声音/震动、重要系统通知。每个类别都有总开关、时间、星期和免打扰时段。短信渠道仅显示在“账号安全短信”说明中，不作为普通提醒开关。

### PRO-05 通知中心

按未读/全部分组，支持系统通知、计划更新、资源下载和账号安全。通知有类型、时间、已读状态、深链目标；重要通知不能被普通清空操作误删。

### PRO-06 下载与缓存

显示男性/女性基础模型、高精度模型、动作媒体、计划内容的下载状态、占用空间、版本和删除按钮。删除高精度包不影响已缓存的基础低精度模型。

### PRO-07 账号与隐私

包含手机号脱敏、设备管理、协议、数据导出、删除账号、注销登录。删除账号流程必须说明延迟删除期、可撤回期限和会被永久清除的数据。

### PRO-08 帮助与反馈

展示常见问题、动作安全说明、联系支持、问题分类、文字描述和最多 3 张图片附件。反馈必须显示工单编号和状态。

## 5. 推送与本地通知

### 5.1 渠道决策

| 场景 | 渠道 | 允许内容 |
| --- | --- | --- |
| 登录/注册验证码 | 阿里云短信 | 验证码和有效期 |
| 账号安全/重要系统通知 | 阿里云短信 + App Push（可选） | 安全事件、强制更新 |
| 训练提醒 | App Push/本地通知 | 计划名、时间、预计时长 |
| 饮食记录提醒 | App Push/本地通知 | 记录提示，不包含营养诊断 |
| 休息计时 | 本地通知、震动、声音 | 计时结束 |

### 5.2 通知深链

- 训练提醒 → WKT-01；若存在 `ACTIVE/PAUSED` 会话 → 恢复提示。
- 饮食提醒 → NUT-01 对应日期。
- 计划更新 → PLN-03 计划详情。
- 资源下载完成 → PRO-06。
- 账号安全 → PRO-07 或登录设备详情。

深链目标失效时进入目标模块首页，并以 Toast 说明“内容已更新”。

### 5.3 权限拒绝

用户拒绝系统通知后，App 内仍可使用训练计时和计划；在 PRO-04 显示权限状态和前往系统设置按钮。不得循环弹窗或用遮罩阻塞主流程。

## 6. 隐私与账号删除

- 最小化收集手机号、设备标识和必要训练/饮食数据。
- 健康数据默认私有，不提供公开个人主页。
- 导出包含用户资料、训练记录、饮食记录和自定义内容，采用异步任务并提供下载有效期。
- 删除账号先确认影响范围，进入 30 天可撤回期；到期后删除或匿名化账号、个人记录、媒体和推送映射。
- 审计日志保留必要的安全事件，不保留短信验证码明文。

## 7. 验收标准

- 发送验证码有倒计时、频控、错误和重试状态；短信模板符合仅验证码/重要通知的边界。
- 普通提醒永远不会调用短信接口。
- 登录后 token 不落明文，设备退出后 refresh token 立即失效。
- 用户可完成资料编辑、通知开关、数据导出和删除账号流程。
- 所有敏感操作有明确确认、结果反馈和失败恢复路径。
