# YOU GYM 页面清单与逐屏 UI 规格

版本：1.0  
更新日期：2026-08-14  
目标画板：390 × 844  
视觉真源：`../design.md`

## 1. Figma 生成通用要求

- 所有移动端画板使用 390 × 844，另为核心页面生成 360 × 800 验证稿。
- 默认背景为 `#000000`，所有颜色、字体、圆角和阴影引用 `design.md` token。
- 状态栏和 Home Indicator 只用于预览，不做成业务组件。
- 页面左右边距 20px；底部胶囊导航左右边距 16px。
- 根页面显示四项底部导航；沉浸任务隐藏底部导航。
- 使用真实中文文案和真实业务数值，不使用 Lorem Ipsum。
- 3D 人体区域用命名为 `UnityViewport` 的明确占位层或现有原创人体视觉，不使用空白矩形。
- 所有列表项、按钮、输入、导航和面板必须使用 Auto Layout。
- 每个核心页面至少生成默认状态；文档明确要求时同时生成加载、空、错误或权限状态。

## 3. 启动、登录与首次设置

### SYS-01 启动检查

**目的**：完成本地会话、版本、协议和基础资源检查。

**布局**：

1. 纯黑全屏。
2. 中心显示白色 `YOU GYM` 字标，宽度不超过 140px。
3. 字标下方 24px 显示细小黄绿进度指示。
4. 底部安全区上方显示版本号，12px 次要文字。

**状态**：正常进入、离线可继续、强制更新、会话过期。启动页停留超过 2 秒时显示可理解状态文案。

### AUTH-01 手机号登录

**目的**：完成手机号输入、协议确认和验证码发送。

**布局**：

1. 顶部留白后显示品牌眉题 `YOU GYM`。
2. 32px 标题“开始你的训练”。
3. 13px 副标题“手机号用于登录和重要账号通知”。
4. 24px 间距后放置手机号输入框，国家/地区固定展示 `+86`。
5. 协议复选框：“我已阅读并同意《用户协议》和《隐私政策》”。
6. 页面底部放置 48px 黄绿主按钮“获取验证码”。

**交互**：手机号格式错误使用行内提示；未勾选协议时点击按钮，聚焦协议区域而不是直接发送。

**状态画板**：默认、手机号错误、短信发送中、频率限制、网络错误。

### AUTH-02 验证码校验

**布局**：返回按钮、标题“输入验证码”、掩码手机号 `138 **** 8000`、6 位验证码输入、重新发送倒计时、主按钮“登录并继续”。

**状态**：输入中、自动校验中、验证码错误、已过期、重发成功。验证码完整后可自动提交，但必须保留按钮状态反馈。

### AUTH-03 协议与隐私

- 顶部标题和返回按钮。
- 正文使用 14px / 22px 可滚动阅读。
- 当前版本和生效日期位于标题下方。
- 页面底部不固定同意按钮；登录页复选框是同意入口。

### ONB-01 身体基础数据

**进度**：顶部显示 `1 / 4` 和 4px 进度条。

**内容**：性别分段控制器、身高输入、体重输入、目标体重可选。数值输入带单位和步进器。

**主操作**：“下一步”。身高、体重异常值使用解释性提醒，不静默接受。

### ONB-02 训练目标

- 标题“你现在最想改善什么？”
- 单选大列表：减脂、增肌、保持体能、提升力量、功能性训练、其他。
- 每项包含 20px 图标、16px 标题和 12px 一行说明。
- 选中项使用黄绿边框和勾选，不把整张卡片铺满荧光色。

### ONB-03 经验与频率

- 经验使用四项单选：新手、初级、中级、高级。
- 每周训练次数使用 1–7 天步进器或离散选择。
- 选择结果下方实时显示建议：“建议从每周 3 次、每次 35–50 分钟开始”。

### ONB-04 场地与器械

- 场地允许多选：健身房、家庭、户外。
- 器械使用分组多选：自重、哑铃、杠铃、固定器械、弹力带、壶铃、其他。
- 顶部搜索仅在器械项超过一屏时显示。
- 无器械也可以继续，自动推荐自重计划。

### ONB-05 推荐生成完成

- 中心使用黄绿完成环和 24px 标题“准备好了”。
- 展示三行摘要：目标、每周频率、常用场地。
- 主按钮“开始探索人体”。
- 次操作“先看看训练计划”。

## 4. 人体与动作模块

### ANA-01 人体全身探索

**目的**：从身体区域和 3D 模型选择训练目标。

**固定结构**：

1. 状态栏。
2. 品牌眉题 `YOU GYM`。
3. 页面标题“人体探索”和副标题“选择肌肉，开始精准训练”。
4. 48px 身体路径下拉框，示例“胸部 · 胸大肌 · 上束”。
5. `UnityViewport` 3D 舞台，占据页面主要空间。
6. 舞台左上角黄绿状态 `ANATOMY 3D`，下一行显示“正面 · 表层肌肉”。
7. 舞台右上角显示当前模型“男性”。
8. 舞台右侧三个 48px 圆形浮动按钮：层级、快速定位、重置视角。
9. 底部肌肉摘要卡片：眉题、肌肉名、动作数、绿色圆形箭头。
10. 四项底部胶囊导航。

**模型内容**：男性正面全身，胸大肌上束以洋红/暖红高亮；其他肌肉为低饱和暗红；纯黑舞台，无外框。

**交互**：点击路径或肌肉触发 ANA-04；点击快速定位打开 ANA-06；点击模型设置打开 ANA-07。

### ANA-02 身体区域下拉

- 以底部面板展示，不使用系统原生小下拉菜单。
- 标题“选择身体区域”，右上关闭按钮。
- 顶部搜索框支持中文和英文解剖名。
- 区域按上肢、躯干、下肢分组。
- 每行 52px，显示区域名、可选肌肉数和箭头。
- 当前区域使用黄绿圆点和文字。

### ANA-03 解剖层级选择

- 顶部保留返回和路径面包屑。
- 使用四列不可取；手机端使用逐级列表：区域 → 肌群 → 肌肉 → 分部。
- 已选择层级在顶部以可横向滚动路径展示。
- 展示节点使用信息图标；可训练节点显示动作数量。
- 选择最终节点后返回人体舞台并聚焦。

### ANA-04 肌肉聚焦

**与 ANA-01 的差异**：

- 标题改为“胸大肌”。
- 状态改为 `FOCUS MODE`。
- 3D 镜头推进到胸部，人体放大但保留头部和部分躯干上下文。
- 胸大肌上束使用暖红填充、洋红外圈；准星外圈黄绿、中心点青色。
- 底部摘要卡片主按钮使用黄绿色圆形箭头。
- 动画时长 600ms，Smart Animate。

### ANA-05 女性模型聚焦

- 结构和镜头与 ANA-04 一致，模型切换为女性解剖模型。
- 肌肉业务 ID、路径、动作数量完全一致。
- 不以胸部外形遮挡胸大肌高亮；必要时使用透明皮肤层或解剖层。

### ANA-06 快速定位面板

- 底部面板高度约 330px。
- 常用区域使用 2 列列表：肩部、胸部、背部、核心、臀部、大腿、小腿、脚踝与足部。
- 每项包含简洁人体区域图标和动作数量。
- 选择后关闭面板并开始镜头移动。

### ANA-07 模型设置面板

依次展示：

1. 男性 / 女性分段控制器。
2. 正面 / 背面分段控制器。
3. 显示层：浅层、深层、骨骼。
4. 展示开关：起点、止点、肌腱、韧带。
5. 资源状态：已下载大小、清晰度、更新入口。
6. 次级按钮“重置为默认视图”。

### ANA-08 展示节点说明

- 用于肌腱、韧带和起止点。
- 标题显示解剖名和英文名。
- 信息块说明位置、作用和关联肌肉。
- 黄色提示：“该结构用于解剖展示，不能直接作为孤立训练目标”。
- 主按钮“查看相关肌肉”。

### EXE-01 动作筛选

**布局**：

1. 上半部保留胸大肌聚焦 3D 上下文。
2. 下半部深色动作面板，顶部拖拽条。
3. 标题“推荐动作”、数量徽标 `12`、说明“已根据胸大肌上束参与度排序”。
4. 横向筛选胶囊：全部、杠铃、哑铃、器械、自重。
5. 82px 动作列表行：56px 缩略图、动作名、参与度/器械、箭头。
6. 底部黄绿主按钮“查看全部 12 个动作”。

**完整筛选面板**：场地、器械、难度、目标和动作模式。多选项使用复选，互斥项使用分段控制器。

### EXE-02 动作筛选无结果

- 保留肌肉目标和当前筛选条件。
- 标题“没有完全匹配的动作”。
- 说明最可能的限制，例如“当前同时选择了家庭和杠铃”。
- 建议胶囊：“改为哑铃”“查看自重动作”“清除难度”。
- 主按钮“放宽筛选”，次操作“返回人体”。

### EXE-03 动作详情

从上到下：

1. 返回、收藏、更多。
2. 16:9 动作视频封面和播放按钮。
3. 动作名、英文名、难度、器械和场地标签。
4. 肌肉参与图区：主要肌、协同肌、稳定肌，颜色语义固定。
5. 推荐参数：组数、次数/时间、休息、节奏。
6. 标准动作步骤，使用编号列表和关键帧缩略图。
7. 常见错误。
8. 安全提示和不适合人群。
9. 替代、降低难度、提高难度。
10. 底部固定主按钮“加入今日训练”，次按钮“立即开始”。

### EXE-04 动作视频全屏

- 黑色全屏，视频 16:9 或原始比例居中。
- 顶部返回、静音、字幕和播放速度。
- 底部进度条、播放暂停、当前时间/总时长。
- 横屏旋转由用户操作触发，不强制旋转整个 App。

## 5. 快速训练生成器

快速训练生成器借鉴 Workout.cool 将选择拆成连续步骤的思路，但使用 YOU GYM 自有视觉、3D 人体、动作数据和专业规则。它不新增一级导航，从 ANA-06、EXE-01 或 PLN-01 进入。

### QWK-01 快速训练：场地与器械

- 顶部进度 `1 / 5`、标题“你在哪里训练？”和关闭按钮。
- 场地使用健身房、家里、户外三项分段控件；允许多选时改用复选列表，不混合控件语义。
- 器械使用图标 + 名称多选：自重、哑铃、杠铃、壶铃、弹力带、拉力器、固定器械、长凳、引体杆。
- “无器械”是明确选项，选择后清除冲突器械并解释影响。
- 底部主按钮“继续”，返回时保留选择。

### QWK-02 快速训练：目标肌肉

- 顶部进度 `2 / 5` 和已选场地/器械摘要。
- 主区显示多级解剖树和完整已选路径；支持左右侧。
- 提供“在 3D 人体中选择”主入口，跳转 ANA-01 并在返回后保留当前生成器状态。
- 仅展示结构显示说明，不允许作为最终筛选目标。
- 支持选择一个主要目标和最多两个次要目标，超出时给出清晰限制。

### QWK-03 快速训练：选择动作

- 顶部进度 `3 / 5` 和场地、器械、肌肉筛选摘要。
- 动作列表展示主要肌肉匹配、器械、难度和推荐理由。
- 支持多选、查看详情、替代动作和清除单个筛选条件。
- 默认建议 4–8 个动作；超出只提示预计时长，不阻止用户继续。
- 无结果时说明造成冲突的条件并提供一键放宽。

### QWK-04 快速训练：调整参数

- 顶部进度 `4 / 5`，显示预计总时长和动作数量。
- 动作行可拖动排序，展开后编辑组数、次数/时长、休息和可选 RPE。
- 提供热身和拉伸分区，至少各有一项专业审核建议。
- 任何参数建议标注目标和经验依据；用户可恢复推荐值。

### QWK-05 快速训练：生成完成

- 顶部进度 `5 / 5` 和完成状态，不使用庆祝性大插画。
- 摘要显示目标肌肉、场地、器械、动作数、预计时长和主要安全提示。
- 主按钮“开始训练”，次按钮“保存为计划”，文字操作“返回修改”。
- 保存为计划进入 PLN-06 并带入动作和参数；直接开始进入 WKT-01。

## 6. 训练计划与训练执行

### PLN-01 训练计划首页

**布局**：

1. 标题“今天，完成一件小事”。
2. 日期和今日训练摘要。
3. 当前计划主区域：计划名、今日主题、预计时长、动作数量、完成进度。
4. 黄绿主按钮“开始训练”或“继续训练”。
5. 本周 7 天日历条，已完成使用绿色完成点，今天使用黄绿底。
6. 今日动作预览，最多展示 4 个，其余折叠。
7. “浏览计划库”和“管理我的计划”入口。
8. “快速创建训练”入口，进入 QWK-01。
9. 底部导航选中训练计划。

**空状态**：没有计划时显示适合目标的 3 个计划，不显示空白日历。

### PLN-02 计划库

- 顶部搜索和筛选：目标、经验、场地、每周频率。
- 推荐计划横向主卡，普通计划使用单列列表。
- 卡片展示计划名、目标、周期、每周次数、单次时长、器械和适合水平。
- 计划卡主视觉使用真实训练媒体，不使用抽象插画。

### PLN-03 计划详情

- 顶部媒体或肌肉覆盖图。
- 计划名、目标、经验、周期、每周频率、预计时长。
- “为什么推荐给你”说明。
- 周计划按天展开，每天显示目标部位和动作数。
- 热身、主训练、拉伸分别分组。
- 风险提示。
- 底部固定主按钮“加入计划”。

### PLN-04 加入计划确认

- 底部面板。
- 开始日期选择。
- 每周训练日多选。
- 提醒时间开关与时间选择。
- 已有计划时显示替换/并存选择和影响说明。
- 主按钮“确认加入”。

### PLN-05 我的计划

- 进行中、草稿、已完成三个标签页。
- 进行中计划展示当前周、完成率和下一次训练。
- 草稿显示最后编辑时间。
- 计划更多菜单：编辑、复制、归档、删除。

### PLN-06 自定义计划基础

- 输入计划名。
- 选择目标、经验、周期和每周频率。
- 选择主要场地和器械。
- 底部主按钮“编辑训练日”。

### PLN-07 编辑训练日

- 顶部训练日切换。
- 热身、主训练、拉伸三个分区。
- 动作行可拖动排序，拖动手柄使用图标。
- 每行动作支持组数、次数、休息摘要和更多菜单。
- 固定按钮“添加动作”，进入人体或动作库选择。

### WKT-01 训练前概要

- 今日主题、预计时长、动作数和目标肌肉。
- 训练前准备清单：器械、热身、注意事项。
- 可选“今天状态”三档选择：一般、良好、很好。
- 主按钮“开始训练”。

### WKT-02 训练执行

**沉浸布局**：

1. 顶部训练总时间、进度 `2 / 5`、暂停按钮。
2. 当前动作名和小型视频/关键帧。
3. 目标肌肉和安全提示一行摘要。
4. 训练组表：组号、上次、重量、次数、完成按钮。
5. 当前组突出左侧黄绿指示，不给整行铺满荧光色。
6. 下方“添加一组”“替换动作”“查看动作详情”。
7. 底部主操作根据状态显示“完成本组”或“下一个动作”。

### WKT-03 休息计时

- 在训练执行页上方打开全屏或大面板状态。
- 48px 倒计时数字和黄绿环形进度。
- 三个操作：减 15 秒、跳过、加 15 秒。
- 下一个动作/组预览。
- 剩余 10 秒显示文字和触觉反馈状态。

### WKT-04 替换动作

- 标题“替换上斜杠铃卧推”。
- 当前目标肌肉、器械和难度作为默认筛选。
- 替代动作列表说明差异，例如“器械不同”“难度更低”。
- 选择后确认是否继承组数和休息时间。

### WKT-05 暂停与退出确认

- 对话框标题“结束这次训练？”
- 展示已完成动作、组数和时长。
- 操作：继续训练、保存并结束、放弃记录。
- 放弃记录使用错误色文字，放在最后。

### WKT-06 训练总结

- 完成状态图标和标题“训练完成”。
- 训练时长、完成组数、训练容量、目标部位四项摘要。
- 个人纪录使用黄绿徽标。
- 主要动作表现列表。
- 备注输入。
- 主按钮“保存并完成”，次操作“分享摘要”预留但首版可隐藏。

### HIS-01 训练历史

- 月份切换和日历热力图。
- 本月训练次数、时长、容量摘要。
- 按日期排列训练记录。
- 空月份显示切换月份和开始训练入口。

### HIS-02 单次训练详情

- 日期、计划、时长、完成状态。
- 每个动作和每组具体重量、次数、RPE。
- 总容量和个人纪录。
- 支持复制为新训练或添加到计划。

### HIS-03 训练趋势

- 时间范围：4 周、12 周、6 个月、1 年。
- 指标：训练次数、时长、容量、动作重量、体重。
- 图表下方必须有文字结论和数据完整性说明。

## 7. 饮食管理

### NUT-01 饮食首页

1. 标题“今日营养”和日期切换。
2. 大型剩余热量环或进度条，显示目标、已摄入、剩余。
3. 蛋白质、碳水、脂肪三项固定语义颜色指标。
4. 早餐、午餐、晚餐、加餐列表，每项显示已记录食物摘要和热量。
5. 每个餐次提供明确的加号图标按钮。
6. 底部导航选中饮食管理。

### NUT-02 食物搜索

- 搜索框自动聚焦。
- 来源标签“FatSecret”。
- 搜索前显示最近使用、收藏、常用餐组合。
- 搜索中显示局部骨架，不清空最近列表。

### NUT-03 搜索结果

- 每行展示食物名、品牌、基准份量、热量和宏量营养摘要。
- 区分通用食物、品牌食物和用户自定义食物。
- 支持每 100g / 每份显示切换。
- 无结果提供“创建自定义食物”。

### NUT-04 食物详情与份量

- 食物名、品牌、数据来源。
- 份量单位下拉和数量步进器。
- 热量和三大营养素实时更新。
- 详细营养成分列表可折叠。
- 选择餐次和记录时间。
- 底部主按钮“记录到午餐”。

### NUT-05 记录确认

- 底部面板展示食物、份量、餐次、热量和宏量营养变化。
- 主按钮“确认记录”。
- 重复记录时提示“今天已记录过该食物”。

### NUT-06 餐次详情

- 餐次标题、总热量、目标占比。
- 食物列表支持编辑份量、移动餐次和删除。
- 底部“继续添加食物”。

### NUT-07 自定义食物

- 名称、品牌可选、基准份量、单位、热量、蛋白质、碳水、脂肪。
- 可选上传包装或营养表图片。
- 表单顶部提示“请按包装营养成分填写”。
- 数据异常时阻止保存并说明字段。

### NUT-08 饮食历史

- 周/月切换。
- 平均热量、蛋白质达标天数和连续记录天数。
- 每日列表显示目标完成度。
- 图表使用固定营养颜色。

## 8. 个人、认证和系统页面

### PRO-01 个人首页

- 头像、昵称、目标和训练经验。
- 连续训练、本月训练、完成组数三项摘要。
- 快捷入口：身体数据、目标、历史、提醒。
- 设置列表：下载与缓存、通知、账号与隐私、帮助、关于。
- 底部导航选中个人。

### PRO-02 身体数据

- 性别、身高、体重、目标体重。
- 体重历史小型趋势图。
- 敏感数据说明。
- 保存按钮仅在有修改时启用。

### PRO-03 目标与经验

- 当前目标、经验、每周频率、场地和器械。
- 修改目标时说明会影响计划和营养推荐，但不删除历史。

### PRO-04 提醒设置

- 训练提醒、计划开始、饮食记录、休息日、重要通知。
- 每项使用开关和可展开时间设置。
- 短信渠道只在“账号安全和重要通知”中展示。
- 通知权限关闭时显示系统设置入口。

### PRO-05 通知中心

- 今天、更早两个时间分组。
- 类型图标：训练、饮食、系统、安全。
- 未读使用黄绿点，不使用整行高亮。
- 点击打开对应深链接。

### PRO-06 下载与缓存

- 基础模型、男性高精度、女性高精度、深层肌肉、骨骼、动作视频缓存。
- 显示大小、版本、状态和删除按钮。
- 下载进度可以暂停和继续。
- 删除高精度资源不影响基础模型。

### PRO-07 账号与隐私

- 手机号、更换手机号、登录设备、协议、隐私政策、导出数据、删除账号、退出登录。
- 删除账号使用独立危险流程和二次验证。

### PRO-08 帮助与反馈

- 常见问题分类、搜索、问题反馈、专业内容纠错、崩溃反馈。
- 内容纠错支持关联当前动作或肌肉 ID。

### SYS-02 离线状态

- 顶部非阻塞横幅“当前离线，记录将在联网后同步”。
- 已缓存计划、基础模型和训练执行继续可用。
- 依赖网络的搜索和资源下载显示明确不可用状态。

### SYS-03 通知权限说明

- 系统权限前置说明页或对话框。
- 说明训练提醒的价值和用户可随时关闭。
- 操作“允许通知”“暂不”。

### SYS-04 Unity 资源下载

- 资源名、清晰度、下载大小、网络类型和进度。
- 操作：后台下载、暂停、使用基础模型继续。
- 移动网络下下载大于阈值时二次确认。

### SYS-05 强制更新

- 品牌、更新标题、必要原因和版本号。
- 单一主按钮“立即更新”。
- 不显示关闭按钮；非强制更新使用可跳过版本。

| NUT-02 | 搜索前、搜索中、失败 |
| PRO-04 | 权限开启、系统权限关闭 |

## 10. 原型流程起点

Figma 至少建立以下独立 Flow：

1. `Flow / 新用户登录与首次设置`：SYS-01 → AUTH-01 → AUTH-02 → ONB-01~05 → ANA-01。
2. `Flow / 人体选肌与动作`：ANA-01 → ANA-04 → EXE-01 → EXE-03。
3. `Flow / 加入并完成训练`：EXE-03 → PLN-01 → WKT-01~06 → HIS-02。
4. `Flow / 记录一餐`：NUT-01 → NUT-02 → NUT-03 → NUT-04 → NUT-05 → NUT-01。
5. `Flow / 设置训练提醒`：PRO-01 → PRO-04 → SYS-03 → PRO-04。
