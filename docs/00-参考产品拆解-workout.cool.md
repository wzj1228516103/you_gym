# 参考产品拆解：Workout.cool

版本：1.0  
更新日期：2026-08-14  
参考地址：https://workout.cool/

## 1. 使用边界

Workout.cool 作为产品流程和信息组织参考，不作为可直接复制的品牌资产来源。YOU GYM 可以借鉴公开页面中的交互模式、任务顺序和信息密度，但不能原样复制其商标、文案、插画、视频、代码、完整页面构图或专有内容库。

本项目仍以 `design.md` 为唯一视觉规范；参考站点不能覆盖 YOU GYM 的无广告、专业审核、3D 人体、移动端四个一级模块和 Fitness Neon V2 视觉方向。

## 2. 观察到的核心结构

公开首页将训练生成拆成三个连续步骤：

1. 设备：选择自重、哑铃、杠铃、壶铃、弹力带、配重片、引体向上杆、长凳等。
2. 肌肉：选择训练目标。
3. 练习：从匹配动作中自定义锻炼。

公开导航还包含训练创建、课程、统计、工具、排行榜和 Premium。课程卡展示目标/等级、周期、单次时长、周频率和器械。

## 3. 值得吸收的模式

### 3.1 三步生成器

“器械 → 肌肉 → 动作”让用户在没有完整计划时也能快速得到可执行训练。每一步只有一个明确问题，支持返回修改，最终结果可继续编辑。

YOU GYM 应转化为：

```text
场地与器械
  → 3D 人体或区域下拉选择肌肉
  → 匹配动作列表
  → 组数/次数/休息建议
  → 开始临时训练或保存为计划
```

同时保留人体优先路径：

```text
3D 人体选中肌肉
  → 镜头聚焦和高亮
  → 动作筛选
  → 再补充器械/场地条件
```

两条路径共用同一筛选结果，不建立两套动作逻辑。

### 3.2 计划卡信息

计划卡应能在不打开详情时回答：适合谁、持续多久、每次多久、每周几次、需要什么器械。YOU GYM 的 PLN-02 列表卡采用同类信息层级，并增加审核信息、目标肌肉和“为什么推荐”。

### 3.3 创建与浏览分离

参考站点把“创建训练”和“浏览课程”分开。YOU GYM 在训练首页应明确区分：今天执行、计划库、自定义计划、从肌肉生成临时训练，避免一个页面同时承担过多编辑任务。

### 3.4 统计是训练后的闭环

统计入口与训练创建并列，强调记录后的回报。YOU GYM 不增加一级“统计”，而是在训练模块内保留历史和趋势，并在个人首页提供摘要。

## 4. 不采用的部分

- 广告和“移除广告”：YOU GYM 全程无广告，不设计广告占位。
- Premium/捐赠：首版不进入 UI，不制造锁定卡片。
- 排行榜：与新手、专业和隐私定位不一致，首版移除。
- 桌面侧栏：YOU GYM 是移动端 App，使用四栏底部胶囊导航。
- 仅设备图标的选择：无障碍和新手识别不足，YOU GYM 使用图标 + 名称 + 选中状态。
- 过于粗粒度的肌肉选择：YOU GYM 使用区域 → 肌群 → 肌肉 → 肌束/分部的多级树和 3D 聚焦。
- 未说明审核来源的动作处方：YOU GYM 的动作、计划和风险提示必须专业审核。

## 5. 对页面清单的影响

在既有页面不新增一级模块，补充以下组合状态：

- ANA-01 增加“快速生成训练”图标按钮，默认收纳，不遮挡人体。
- ANA-06 快速定位面板增加“按区域”和“按训练意图”两个入口。
- EXE-01 顶部以筛选摘要显示场地、器械、肌肉和难度，任何条件可单独清除。
- PLN-01 增加“快速创建”入口，打开三步生成底部全屏流程。
- PLN-06 支持把筛选结果保存为自定义计划。
- WKT-01 支持没有长期计划的临时训练。

三步生成器在 Figma 中作为以下状态设计，不新增底部 Tab：

| 状态 ID | 名称 | 关键内容 |
| --- | --- | --- |
| QWK-01 | 选择场地与器械 | 场地分段控件、器械多选、无器械选项 |
| QWK-02 | 选择目标肌肉 | 3D 缩略舞台/跳转主人体、区域树、已选路径 |
| QWK-03 | 选择动作 | 匹配动作、推荐理由、替代动作、多选 |
| QWK-04 | 调整训练参数 | 动作排序、组数、次数、休息、预计时长 |
| QWK-05 | 生成完成 | 开始训练、保存为计划、返回修改 |

## 6. Figma 参考规则

Figma 生成时可以参考三步流程的简洁性和计划卡的信息顺序，但必须使用 `design.md` 的黑色背景、荧光黄绿主操作、洋红肌肉语义、Noto Sans、单层卡片和移动端安全区。

不得出现 Workout.cool 名称、logo、广告、Premium、排行榜、原文案或其页面截图作为最终设计资产。参考截图只能放在 Figma `99_References` 页面并标记“仅供流程参考，不可交付”。

## 7. 验收问题

- 新用户是否能在每一步理解自己要做什么？
- 用户能否从 3D 肌肉和快速生成器两条路径得到同一批动作结果？
- 返回上一步是否保留已选器械和肌肉？
- 结果是否解释“为什么匹配”，而非只给动作列表？
- 临时训练是否能直接开始，也能保存为长期计划？
