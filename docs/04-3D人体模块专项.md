# YOU GYM 3D 人体模块专项规格

版本：1.0  
更新日期：2026-08-14  
责任边界：React Native 页面与状态、Unity 渲染与交互、后端解剖树与动作映射

## 1. 模块目标

3D 人体模块不是独立的解剖百科，而是训练发现入口。用户应该能够：

1. 快速找到身体区域。
2. 逐级定位肌群、具体肌肉和有训练意义的肌肉分部。
3. 在男性与女性模型中获得一致的选择结果。
4. 通过镜头推进和高亮理解目标位置。
5. 从目标肌肉进入匹配动作，而不是进入无关内容列表。
6. 查看深层、骨骼、肌腱、韧带和起止点，但理解哪些结构不能直接训练。

## 2. 业务层级

```text
Region 身体区域
└── Group 肌群 / 功能群
    └── Muscle 具体肌肉
        └── Part 肌肉分部 / 肌头 / 有训练意义的纤维区域
            └── Attachment 展示型起点、止点、肌腱、韧带
```

## 4. ID 与对象命名

### 4.1 业务 ID

```text
region_chest
group_pectorals
muscle_pectoralis_major
part_pectoralis_major_clavicular
attachment_pectoralis_major_clavicular_origin
```

规则：

- 全部小写 snake_case。
- 业务 ID 使用英文解剖名，不包含模型版本、性别或左右标记。
- 左右侧通过 `side` 参数表达；只有左右结构确实需要独立记录时才派生 ID。
- 已发布 ID 不复用、不改义；名称变化通过字段更新。

### 4.2 Unity 对象名

```text
ANAT_M_PectoralisMajor_Clavicular_L_LOD0
ANAT_F_PectoralisMajor_Clavicular_L_LOD0
```

对象名包含：模块前缀、性别、解剖名、侧别、LOD。业务端不得直接依赖对象名筛选动作。

## 5. 选择与命中

- 每个可点击结构使用简化代理网格或碰撞体，避免直接用高精度网格射线检测。
- 点击空白区域不清空当前选中，轻触舞台空白只关闭浮层。
- 相邻细小肌肉命中冲突时，先显示候选列表，不擅自选择面积最大的结构。
- 用户旋转手势移动超过阈值时判定为拖动，不触发点击。
- 点击展示节点时进入 ANA-08，不进入动作筛选。
- 双侧肌肉默认同时高亮；用户开启单侧模式后才独立选择左/右。

### 5.1 视觉基准与表面材质

当前视觉基准使用 `assets/references/workout-muscle-selector-reference.png`。只参考人体的正反面构图、冷灰蓝肌肉分区、白色边界和深灰背景，不复制参考页面的步骤条、按钮、文案或品牌。

- 默认全身选择状态：同一性别正面与背面并排、同高度、同缩放，四肢完整入镜。
- 主材质：`#9AA8BB`；深度/背光面：`#6F7D91`；非训练结构：`#777B80`。
- 人体外轮廓与主要肌肉分区线：`#F5F7FA`，屏幕空间视觉宽度约 1.25–2px。
- 舞台：`#232323` 或更深，不使用浅色径向渐变。
- Unity 采用 Toon/Lit 混合 Shader：保留真实网格体积和光照，但压低高光、减少皮肤感，用轮廓和分区贴图建立清晰度。
- 分区白线来自独立 mask/贴图或可控边界渲染，不依赖网格缝隙，避免缩放时断裂和闪烁。
- 头、手和足保持中性，不绘制面部细节，不用写实皮肤、毛发、血管和油亮反射。
- 男性与女性使用同一材质体系，但保持各自真实解剖比例；不得仅通过缩放男性模型得到女性模型。

未选择时正反面都可点击。选择后先确定目标属于正面、背面或侧面，再把相应模型提升为主视图；另一模型在 150–220ms 内淡出至 20%–35%，随后执行镜头推进。返回全身时恢复双模型构图。

HTML/Figma 临时占位使用 `assets/anatomy/anatomy-front-back-placeholder.png`，生产环境仍由 Unity 模型实时渲染。

## 6. 镜头系统

### 6.1 预设字段

| 字段 | 说明 |
| --- | --- |
| `targetPosition` | 目标中心世界坐标 |
| `cameraPosition` | 镜头目标位置 |
| `fieldOfView` | 视场角 |
| `viewSide` | front、back、left、right |
| `minDistance` | 最小缩放距离 |
| `maxDistance` | 最大缩放距离 |
| `focusPadding` | 目标周围保留上下文比例 |

### 6.2 动画

- 默认 600ms，范围 550–750ms。
- 相机位置、朝向和视场角同步插值。
- 0–35%：整体镜头开始移动。
- 35–75%：目标高亮渐入，其他结构降低明度。
- 75–100%：准星和摘要卡片稳定进入。
- 新目标选择取消旧动画并从当前相机状态继续。
- 开启减少动态效果后改为 200ms 淡入淡出。

## 7. 高亮材质

| 角色 | 颜色 | 视觉规则 |
| --- | --- | --- |
| 主要目标 | `#FF2D55` 到 `#FF4B3E` | 实体填充、轮廓和轻微脉冲一次 |
| 协同肌 | 暖红 45–60% 透明度 | 不显示强外圈 |
| 稳定肌 | `#35E6E8` 30–45% | 仅在详情或解释模式显示 |
| 准星外圈 | `#B3FF00` | 1.5–2px 线条 |
| 准星中心 | `#35E6E8` | 6–8px 实心点 |
| 无关结构 | 原色降低 35–55% 明度 | 保留人体轮廓 |

- 材质使用 MaterialPropertyBlock，避免为每块肌肉实例化材质。
- 高亮不能造成过曝或隐藏肌肉纹理。
- 选中高亮覆盖冷灰蓝基础材质，但保留白色分区线；洋红不得把相邻肌肉边界糊成一片。
- 高亮状态必须有文字路径，满足色觉差异用户。

## 8. 男女模型

- 使用相同业务节点树和动作映射。
- 分别维护对象映射表和相机预设，不能假设网格拓扑完全相同。
- 相同肌肉的高亮面积和镜头构图应表达同一结构，不要求像素一致。
- 模型切换保留当前节点、层级、视角侧和筛选条件。
- 当前模型缺失某展示资源时使用基础层并显示资源状态，不回退到另一性别模型。

## 12. 性能与降级

- 基础模型首次可交互目标：中端设备 2.5 秒内，缓存后 1.2 秒内。
- 活跃场景目标 45–60 FPS；连续低于 30 FPS 时自动降低 LOD 和后处理。
- 活跃三角面建议 150k–250k，至少三级 LOD。
- 纹理以 1K/2K 为主，使用 ASTC 或 ETC2。
- 离开人体模块后暂停 Unity 渲染；内存压力时释放高精度层。
- Unity 启动失败时展示文字解剖导航、模型静态占位和重试入口，动作筛选仍可使用。

## 13. Figma 表达要求

- 建立男性全身、男性聚焦、女性聚焦、深层、骨骼和资源加载至少六种状态。

- 图层名称保持 `UnityViewport`，3D 模型内部无需在 Figma 中复制真实 Unity 层级。
- 浮动工具、路径导航、摘要卡和底部面板使用设计系统组件实例。
- 原型中点击路径或肌肉进入聚焦，点击绿色箭头进入动作筛选。

## 14. 验收标准

- 男性与女性模型均可加载、旋转、缩放和重置。
- 同一 nodeId 在男女模型中映射正确。
- 选择可训练节点后 750ms 内完成镜头和高亮状态。
- 连续快速选择不会出现旧目标覆盖新目标。
- 展示节点不会错误进入动作筛选。
- 远程资源失败时基础模型和文字导航可用。
- 核心设备无持续低于 30 FPS、明显闪烁或空白画布。
- 浮动控件、标签和高亮在 360 × 800 与 430 × 932 下不重叠。
