版本：1.0  
更新日期：2026-08-14  
候选仓库：https://github.com/hasaneyldrm/exercises-dataset

## 1. 结论

该仓库适合作为 YOU GYM 动作库的“结构化种子数据”和搜索冷启动数据，不适合作为未经处理的生产内容源。

可复用的非媒体内容：动作名称、分类、器械、目标肌肉、辅助肌肉、多语言步骤和数据结构。仓库声明这些内容及代码/结构采用 MIT License，但仍需保留版权声明和来源记录。

不可默认复用的媒体：`images/` 和 `videos/` 中的缩略图与 GIF。仓库明确声明媒体属于 Gym visual，MIT 不覆盖媒体；使用前必须从 Gym visual 获取 YOU GYM 自己的许可，并遵守 180 × 180 分辨率和归属要求。正式动作详情优先使用已授权自有视频或原创 3D 动画。

## 3. 原始字段与 YOU GYM 映射

| 原始字段 | YOU GYM 字段 | 处理 |
| --- | --- | --- |
| `id` | `sourceExerciseId` | 保留字符串，不能直接当内部 ID |
| `name` | `sourceName` / `nameZh` | 中文名称需编辑校对 |
| `category` / `body_part` | `bodyRegionHint` | 仅作初始筛选，不替代解剖树 |
| `equipment` | `equipmentHint` | 归一化到 YOU GYM 枚举 |
| `target` | `targetHint` | 建立人工审核映射 |
| `muscle_group` | `muscleGroupHint` | 作为辅助信息 |
| `secondary_muscles` | `secondaryHints` | 不能自动发布为协同肌 |
| `instruction_steps.zh` | `draftStepsZh` | 初稿，必须内容编辑和专业审核 |
| `instructions.*` | `sourceTranslations` | 记录语言来源和版本 |
| `image` / `gif_url` | `sourceMediaRef` | 仅在媒体授权后进入资源流程 |
| `attribution` | `sourceAttribution` | 始终保留，随资源审计 |
| `created_at` | `sourceCreatedAt` | 不作为发布时间 |

导入后新增：`riskLevel`、`commonErrors`、`safetyWarnings`、`stopConditions`、`recommendedParameters`、`progression`、`regression`、`reviewStatus`、`reviewVersion`、`professionalReviewerId`、`mediaLicenseStatus`。

## 4. 目标肌肉映射初稿

以下只作为后台导入时的候选映射，不能自动发布；每条映射需由专业审核人确认：

| 原始 `target` | 候选 YOU GYM 节点 | 规则 |
| --- | --- | --- |
| `abs` | 腹部 → 腹肌群 → 腹直肌/腹外斜肌 | 由动作模式和视频进一步确认 |
| `abductors` | 髋部 → 髋外展肌群 | 不强行归为臀大肌 |
| `adductors` | 髋部 → 髋内收肌群 | 作为肌群级目标 |
| `biceps` | 上臂 → 肱二头肌 | 不拆分为细小束除非有依据 |
| `calves` | 小腿 → 小腿三头肌群 | 可继续映射腓肠肌/比目鱼肌 |
| `delts` | 肩部 → 三角肌 | 前/中/后束需人工核对 |
| `glutes` | 臀部 → 臀肌群 → 臀大肌/臀中肌 | 按动作和视频细分 |
| `hamstrings` | 大腿后侧 → 腘绳肌群 | 不自动断言单一肌肉 |
| `lats` | 背部 → 背阔肌 | 允许协同肌保留 |
| `levator scapulae` | 肩胛带 → 提肩胛肌 | 需要专业复核 |
| `pectorals` | 胸部 → 胸大肌 | 上/中/下束需要动作依据 |
| `quads` | 大腿前侧 → 股四头肌群 | 可映射股直肌等分部 |
| `serratus anterior` | 胸廓侧面 → 前锯肌 | 训练筛选节点需满足最低动作数 |
| `traps` | 背部/肩部 → 斜方肌 | 上/中/下束需人工核对 |
| `triceps` | 上臂 → 肱三头肌 | 长头/外侧头/内侧头需人工核对 |
| `upper back` | 背部 → 上背部肌群 | 作为宽泛筛选，不宣称单肌孤立 |
| `spine` | 仅展示结构/脊柱稳定 | 禁止作为直接肌肉目标 |
| `cardiovascular system` | 训练类型 → 心肺 | 不写入解剖肌肉目标 |

如果同一动作的 `target` 与 `secondary_muscles` 映射到多个节点，系统保存主要、协同、稳定三种角色和审核依据。没有足够证据时使用肌群级节点。

## 5. 导入流程

```text
锁定仓库提交
  → 下载非媒体 JSON/schema
  → 校验 JSON Schema、ID、字段和中文完整度
  → 归一化名称、器械、场地、动作模式
  → 生成解剖节点候选映射
  → 去重和人工合并
  → AI 补充错误/安全/参数初稿
  → 内容编辑校对
  → 专业审核
  → 绑定已授权媒体或原创媒体
  → 发布 YOU GYM 内容版本
```

导入任务必须记录仓库 URL、commit、导入时间、脚本版本、原始文件 hash、处理人和失败记录。后续同步只允许以新 commit 生成新批次，不能静默覆盖已发布动作。

## 6. 媒体策略

### 6.1 当前阶段

- 不把仓库 GIF/图片复制进生产对象存储。
- UI/Figma 可使用带“第三方媒体待授权”标签的低风险示例，仅用于内部原型评审。
- 动作详情的最终设计使用 `Asset/Exercise/Placeholder` 或已授权自有媒体。

### 6.2 获得授权后

- 服务端保存媒体许可编号、授权主体、允许平台、分辨率、期限和归属文本。
- 资源通过对象存储/CDN 私有签名 URL 分发。
- 180 × 180 原始限制不满足详情页时，不能自行放大冒充高清素材；应采购更高规格或制作原创演示。
- 用户端显示来源/归属的方式由法务和产品确认，后台必须能追溯。

## 7. 内容缺口

该数据集没有 YOU GYM 发布所需的完整安全层：

- 常见错误并非结构化字段。
- 没有统一风险等级和停止条件。
- 没有按目标/经验配置的组数、次数、休息和 RPE 范围。
- 没有热身、拉伸、替代动作和降阶/进阶结构。
- 目标肌肉粒度低于 YOU GYM 的多级解剖树。
- 中文步骤需要术语统一、事实校验和专业审核。

因此导入动作默认状态为 `AI_GENERATED` 或 `DRAFT`，禁止直接进入 `PUBLISHED`。

## 8. 验收标准

- 导入后 1324 条 source ID 无重复，重复名称能通过器械/目标/来源区分。
- 中文步骤完整性、字段类型和媒体引用通过自动校验。
- 所有 target 映射有审核状态，`spine` 和 `cardiovascular system` 不作为孤立肌肉筛选目标。
- 未确认 Gym visual 许可时，生产资源中没有该仓库媒体。
- 任何发布动作都有 YOU GYM 自己的安全提示、训练参数、审核记录和版本。
