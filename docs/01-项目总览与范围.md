# YOU GYM 项目总览与范围

版本：1.0  
状态：产品和设计基线  
更新日期：2026-08-14

## 1. 产品定义

YOU GYM 是一款同时支持 iOS 和 Android 的无广告健身 App。产品以可交互 3D 人体解剖模型为核心入口，把“我想练哪里”转换为可执行的动作筛选、训练计划、训练记录和饮食管理。

核心价值表达：

> 选择身体目标，看懂肌肉，完成训练，持续记录。

产品不是医学诊断工具，也不承诺单个动作可以完全孤立训练某一细小肌束。专业性来自准确的解剖映射、明确的训练贡献关系、可靠的动作内容和可解释的计划，而不是无限增加解剖名词。

## 2. 产品原则

1. **无广告**：训练、记录和学习过程中不出现横幅、插屏或激励广告。
2. **人体优先**：用户可以直接从身体区域和具体肌肉开始，而不必先理解训练分类。
3. **可执行**：所有知识内容最终能够进入动作、计划或记录流程。
4. **专业但不误导**：区分主要肌、协同肌和稳定肌；区分展示节点与可训练节点。
5. **适合新手**：首次出现专业术语时提供通俗说明和安全提示。
6. **跨场景**：同一肌肉可以按健身房、家庭和户外条件筛选动作。
7. **渐进加载**：基础能力离线可用，高精度 3D 和媒体资源按需加载。
8. **数据敏感**：身体、训练、饮食数据按敏感个人信息处理。

## 3. 目标用户

### 3.1 健身新手

- 核心问题：不知道练哪里、做什么、动作是否安全。
- 首要功能：人体定位、初级动作、标准步骤、低风险计划、计时和提醒。
- 设计重点：少术语、明确主操作、解释为什么推荐。

### 3.2 减脂用户

- 核心问题：训练和饮食无法持续，缺少热量与趋势反馈。
- 首要功能：减脂计划、训练频率、热量和宏量营养记录、体重趋势。
- 设计重点：剩余热量、连续记录、每周进度，不制造体重焦虑。

### 3.3 增肌用户

- 核心问题：计划执行不稳定，重量和训练容量难追踪。
- 首要功能：分化计划、组数/次数/重量、历史记录、动作重量趋势。
- 设计重点：上次训练数据、递增提示、训练容量。

### 3.4 家庭训练者

- 核心问题：器械有限，通用计划中大量动作无法执行。
- 首要功能：场地与器械筛选、自重/弹力带/哑铃动作、替代动作。
- 设计重点：快速筛选“家里能做”的动作。

### 3.5 功能性训练者

- 核心问题：关注动作模式、稳定性、核心和活动度，而非单一围度。
- 首要功能：动作模式、关节、稳定肌、活动度和功能性计划。
- 设计重点：明确训练目的与风险，不使用健美孤立训练话术。

## 4. 使用场景

| 地点 | 典型条件 | 设计与功能要求 |
| --- | --- | --- |
| 健身房 | 器械丰富、网络可能不稳定、单手操作 | 大点击区、快速组记录、缓存视频 |
| 家庭 | 器械有限、空间有限 | 自重与少器械筛选、安静动作提示 |
| 户外 | 光照强、网络波动、可能戴手套 | 高对比、离线计划、较大按钮 |

## 5. 一级模块

### 5.1 人体

完成从解剖定位到动作筛选的任务：

```text
区域 → 肌群 → 肌肉 → 肌肉分部 → 3D 聚焦 → 动作筛选
```

### 5.2 训练计划

完成计划发现、加入、调整、今日训练、训练执行和训练总结。

### 5.3 饮食管理

完成营养目标、食物搜索、份量选择、餐次记录和每日趋势。

### 5.4 个人

承载身体数据、目标、经验、提醒、历史入口、下载管理、隐私和系统设置。

## 6. 首版范围

### 6.1 P0：首版必须完成

- 手机号验证码注册与登录。
- 首次身体数据、训练目标、经验、场地和器械设置。
- 男性和女性基础 3D 模型。
- 身体区域、肌群、具体肌肉、可训练肌肉分部导航。
- 3D 旋转、缩放、重置、正背面、层级切换、肌肉点击与高亮。
- 选择肌肉后的动作筛选。
- 动作库、动作详情、标准步骤、常见错误和安全提示。
- 预设训练计划、今日训练和训练执行。
- 组数、次数、重量、时间、休息记录。
- 训练历史与基础趋势。
- FatSecret 食物搜索、份量选择、餐次和宏量营养记录。
- 身体数据和提醒设置。
- 阿里云短信验证码与重要通知。
- App Push / 本地训练和饮食提醒。
- Vue 管理后台中的内容维护和审核。

### 6.2 P1：首版后增强

- 自定义训练计划编辑器增强。
- 更完整的深层肌肉、骨骼、肌腱、韧带和起止点资源。
- 食谱和组合餐。
- 更丰富的训练趋势和个人纪录。
- 穿戴设备与健康平台同步。
- 多语言内容。

### 6.3 明确不在首版

- 社区、评论、点赞、私信。
- 在线私教实时视频。
- 摄像头动作识别和自动纠错。
- 医疗诊断、康复处方、疾病治疗建议。
- 付费商城、广告和复杂会员体系。
- 把所有模型和高清视频打入安装包。

## 7. 核心成功指标

### 7.1 激活

- 完成手机号登录的用户中，首次设置完成率。
- 首次设置后 24 小时内完成一次肌肉选择的比例。
- 肌肉选择后进入动作详情或计划的比例。

### 7.2 训练

- 首周完成至少一次训练的用户比例。
- 训练开始到训练总结的完成率。
- 每周训练天数和连续训练周数。
- 训练组记录完整率。

### 7.3 饮食

- 首周完成至少一天饮食记录的用户比例。
- 食物搜索到记录成功的转化率。
- 连续三天记录饮食的比例。

### 7.4 质量

- 3D 模型首个可交互时间。
- 3D 资源下载成功率。
- 训练执行页崩溃率和计时异常率。
- 短信验证码成功率。
- 内容投诉和专业纠错率。

## 8. 角色与权限

| 角色 | 能力 |
| --- | --- |
| 游客 | 查看登录、协议和有限产品预览，不保存敏感数据 |
| 登录用户 | 使用全部首版客户端功能 |
| 内容编辑 | 创建动作、计划、饮食说明和媒体草稿 |
| 专业审核员 | 审核动作步骤、解剖映射、训练参数和风险提示 |
| 运营人员 | 发布内容、管理推荐位、查看运营数据 |
| 客服 | 查看必要的账号状态和通知记录，不查看无关敏感内容 |
| 超级管理员 | 角色、权限、系统配置和审计管理 |

## 9. 业务约束

- FatSecret 正式商用前必须完成授权与套餐确认。
- AI 生成内容不能自动发布。
- 阿里云短信不得用于普通训练提醒或营销轰炸。
- 用户未授权通知时仍能在 App 内正常使用计划和记录。
- 3D 高精度资源下载失败时，基础模型和文字导航必须可用。
- 删除账号需要明确影响范围，并按隐私要求处理用户数据。

## 10. 术语

| 术语 | 定义 |
| --- | --- |
| 身体区域 | 胸部、背部、肩部等顶层导航区域 |
| 肌群 | 按解剖或功能组织的一组肌肉 |
| 具体肌肉 | 具有稳定业务 ID 的单块肌肉 |
| 肌肉分部 | 对训练筛选有意义的肌束或肌头，例如胸大肌上束 |
| 展示节点 | 可以在 3D 中查看，但不直接作为训练目标的结构 |
| 可训练目标 | 能够映射到有实际训练意义动作的肌肉节点 |
| 主要肌 | 动作中主要产生力量或承受负荷的肌肉 |
| 协同肌 | 帮助完成动作的肌肉 |
| 稳定肌 | 主要负责保持关节或躯干稳定的肌肉 |
| 训练会话 | 用户从开始训练到结束总结的一次完整记录 |
