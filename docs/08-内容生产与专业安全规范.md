# YOU GYM 内容生产与专业安全规范

版本：1.0  
更新日期：2026-08-14

## 1. 目标与底线

动作、计划、热身、拉伸和风险提示可以由 AI 生成初稿，但任何对用户可见的专业内容必须由具备相应经验的人工审核人批准。AI 输出不能直接发布，不能替代医生、康复师或教练的个体诊断。

内容表达应清晰、克制、可执行。禁止承诺“局部减脂”“完全孤立某一细小肌束”“保证无伤”“短期极速改变”等不可验证结论。

## 2. 动作分类体系

### 2.1 分类维度

每个动作必须同时具有以下结构化分类：

- 动作模式：深蹲、髋铰链、水平推、垂直推、水平拉、垂直拉、弓步、负重行走、旋转、抗旋转、抗伸展、抗侧屈、步态/跳跃、孤立屈伸、移动性。
- 主要训练区域：胸、背、肩、上臂、前臂、核心、臀、大腿前侧、大腿后侧、内收肌群、小腿、踝足、全身。
- 目标解剖节点：引用 `anatomy_node_id`，可多选并标注主要/次要/稳定。
- 器械：自重、哑铃、杠铃、壶铃、弹力带、拉力器、史密斯机、固定器械、TRX/悬吊、药球、泡沫轴、其他。
- 场地：健身房、家庭、户外。
- 难度：入门、初级、中级、高级。
- 运动类型：力量、增肌、肌耐力、心肺、功能性、灵活性、热身、拉伸。
- 姿势：站姿、坐姿、仰卧、俯卧、侧卧、跪姿、悬垂。
- 单/双侧：双侧、交替、左、右、单侧同步记录。
- 冲击等级：低、中、高。

### 2.2 可筛选训练节点

只有能够影响动作筛选并具备训练意义的肌肉或肌束才设置 `selectableForTraining=true`。肌腱、韧带、骨性标志、起止点和过细的解剖结构可以展示，但默认 `selectableForTraining=false`。每个可训练节点至少需要 3 个经过审核的动作映射，否则不得作为独立筛选入口。

## 3. 动作内容模板

### 3.1 基础字段

| 分组 | 必填字段 |
| --- | --- |
| 标识 | 名称、别名、动作 ID、状态、版本 |
| 分类 | 动作模式、难度、场地、器械、主要/次要肌肉 |
| 教学 | 准备姿势、执行步骤、呼吸、动作节奏、结束方式 |
| 训练 | 目标、组数、次数/时长、休息、RPE 区间、进阶/降阶 |
| 安全 | 常见错误、停止条件、风险等级、禁忌/谨慎人群 |
| 媒体 | 封面、关键帧、演示视频、镜像要求、版权来源 |
| 审核 | 作者、AI 生成标记、专业审核人、审核日期、证据备注 |

### 3.2 标准步骤写法

每个动作使用 4–8 个短步骤，每步只描述一个可观察动作。推荐结构：

1. 设置器械和身体位置。
2. 建立支撑、关节对齐和躯干张力。
3. 描述离心阶段轨迹与呼吸。
4. 描述终点标准，不鼓励超范围动作。
5. 描述向心阶段和发力意图。
6. 描述重复间的重置和结束方式。

避免使用“核心收紧”这类无法执行的孤立口号，应改为“呼气后保持肋骨不过度上翻，躯干位置不随负重晃动”。

### 3.3 常见错误模板

每项错误必须包含：错误现象、可能影响、修正提示、是否需要立即停止。例如：

```text
错误：深蹲下降时膝盖明显向内塌陷。
影响：下肢对齐和发力稳定性下降。
修正：降低负重，保持膝盖方向与脚尖大致一致。
停止条件：出现锐痛、麻木或无法控制的关节不稳时停止。
```

### 3.4 训练参数

内容层只提供范围，计划层可覆盖：

| 目标 | 组数 | 次数/时长 | 休息 | 强度表达 |
| --- | --- | --- | --- | --- |
| 新手学习 | 2–3 | 6–12 次 | 60–120 秒 | 保留 3–4 次余力 |
| 增肌 | 3–5 | 6–15 次 | 60–180 秒 | 保留 1–3 次余力 |
| 最大力量 | 3–6 | 1–6 次 | 180–300 秒 | 需充分经验和保护 |
| 肌耐力 | 2–4 | 12–25 次 | 30–90 秒 | 动作质量优先 |
| 等长/核心 | 2–4 | 15–60 秒 | 45–120 秒 | 不屏息、不代偿 |

这些范围不是医疗建议，不作为所有动作的统一处方。高技术、高冲击或高风险动作必须单独覆盖。

## 4. 热身与拉伸规范

### 4.1 热身结构

- 3–8 分钟一般热身，提高体温和呼吸。
- 针对目标关节的动态活动度。
- 目标动作的低负荷练习组。
- 逐级接近工作重量，不用疲劳性静态拉伸替代热身。

### 4.2 拉伸与整理

- 训练后以低强度活动和舒适范围拉伸为主。
- 不承诺拉伸可以治疗疼痛或永久改变体态。
- 每个拉伸动作说明位置、持续时间、呼吸和停止条件。
- 用户报告麻木、锐痛、眩晕或异常胸闷时，立即停止并寻求专业帮助。

## 5. 风险等级

| 等级 | 定义 | 发布要求 | UI 表达 |
| --- | --- | --- | --- |
| L1 低 | 新手可在无监督环境学习 | 1 名专业审核 | 普通提示 |
| L2 中 | 对活动度/稳定性有要求 | 1 名高级审核，必须有降阶动作 | 黄色风险提示 |
| L3 高 | 高负重、高冲击或技术复杂 | 2 人复核，明确保护和先决条件 | 进入前确认提示 |
| L4 限制 | 不适合自助 App 教学 | 不进入普通动作库 | 仅后台可见 |

疼痛不使用 1–10 数字自行诊断。用户出现急性伤病、手术后恢复、孕期、心血管异常等情况时，App 仅提示咨询医生或合格专业人员。

## 6. 媒体制作规范

### 6.1 图片

- 首帧必须清楚展示起始姿势，背景简洁，主体无遮挡。
- 同一动作至少提供起始位与终点位；关键关节不被裁切。
- 竖版主规格 1080 × 1350，横版辅助规格 1920 × 1080，缩略图保持清晰可辨。
- AI 生成的人体图必须检查肢体数量、器械结构、关节角度、文字伪影和左右方向。

### 6.2 视频

- 6–20 秒静音循环为动作列表预览；30–90 秒为详情教学。
- 正面/侧面选择以最能说明轨迹为准，复杂动作可双机位。
- 视频中不加入不可关闭的文字水印；字幕由客户端叠加以支持多语言。
- 禁止把未经授权的教练肖像、品牌器械素材或第三方视频直接重制。

### 6.3 AI 素材标记

后台记录生成模型、提示词版本、生成时间和人工修改人。用户端不必突出 AI 标识，但必须保证演示不误导；高风险动作优先使用真人实拍或专业 3D 动画。

## 7. AI 生成与审核流程

动作库允许从 `hasaneyldrm/exercises-dataset` 导入非媒体种子字段，但导入记录必须锁定仓库 commit 和来源。该数据集的中文步骤可作为草稿，不能跳过 YOU GYM 的术语校对、风险补充和专业审核。

```text
结构化任务单
  → AI 生成文字/媒体初稿
  → 内容编辑校对术语和格式
  → 专业审核动作与风险
  → 媒体质检
  → 预发布环境验证
  → 发布并记录版本
  → 反馈监控和必要下线
```

AI 任务单必须指定动作 ID、目标人群、器械、难度、输出字段、禁用表述和参考资料。生成失败或事实不确定时必须标记 `NEEDS_RESEARCH`，禁止用流畅措辞掩盖不确定性。

## 8. 审核状态和版本

| 状态 | 说明 |
| --- | --- |
| DRAFT | 编辑中，不对用户可见 |
| AI_GENERATED | AI 初稿，等待人工处理 |
| EDIT_REVIEW | 内容编辑审核 |
| PROFESSIONAL_REVIEW | 专业安全审核 |
| MEDIA_REVIEW | 图片/视频质检 |
| APPROVED | 审核通过，待发布 |
| PUBLISHED | 已发布 |
| SUSPENDED | 因风险或错误暂停 |
| ARCHIVED | 历史归档 |

任何影响动作步骤、主要肌肉、风险等级或训练参数的修改都必须产生新版本并重新专业审核。修正错别字可走轻量审核，但必须保留变更日志。

## 9. 用户反馈闭环

动作详情提供“内容问题/动作不适/媒体错误/其他”反馈。风险反馈进入高优先级队列，内容运营 24 小时内分诊；需要下线时可立即切换 `SUSPENDED` 并让客户端隐藏新增入口，历史记录仍保留动作名称快照。

## 10. 验收标准

- 未经 `APPROVED/PUBLISHED` 的内容无法通过 API 返回给普通用户。
- 每个动作都有标准步骤、常见错误、安全提示、参数范围和至少一种降阶方案。
- 可训练肌肉节点与动作映射均有人工审核依据。
- AI 生成的文字和媒体有生成记录、审核人和版本链路。
- 高风险动作的 UI、内容和发布权限符合 L3 规则。
